# EduBridge - AWS EC2 Website Deployment 🚀

EduBridge is a responsive educational landing page website designed and deployed on **Amazon Web Services (AWS EC2)**. This project demonstrates cloud deployment, Linux server configuration, web hosting, and frontend integration using HTML, CSS, and JavaScript.

## 🌐 Live Website

**Deployed Link:**  
http://65.0.125.160

---

## 📌 Project Overview

EduBridge is a modern educational platform landing page created to showcase:

- Online learning opportunities
- Expert mentorship
- Career growth guidance
- Responsive UI design
- Interactive JavaScript functionality

The project was locally developed and later deployed to a live AWS EC2 server.

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Cloud & Deployment
- AWS EC2
- Apache Web Server (httpd)
- Amazon Linux 2023
- SSH (MobaXterm)
- Linux Command Line
